# Данные для тестового задания по бюджету обзвона

## Файлы

- `data/campaigns.csv` — условный ID кампании, тип базы, сценарий, контакты, звонки и расход на обзвон в рублях.
- `data/outcomes.csv` — условный ID кампании, лиды, назначенные встречи, состоявшиеся встречи и договоры.

Соедини файлы по `campaign_id`. Одна строка соответствует одной кампании (отдельному запуску). `base_type` объединяет запуски одного типа базы. `script_id` обозначает сценарий обзвона и может повторяться у разных типов баз.

`contacts` — уникальные контакты внутри кампании. При суммировании по группе один человек может учитываться в нескольких кампаниях. `calls` — число звонков. `call_cost_rub` — их суммарная стоимость.

Лиды учитываются по отметке кампании в CRM. В назначенные встречи входят назначенные, отменённые и состоявшиеся встречи, а также договоры. Состоявшиеся встречи включают договоры.

Выгрузка охватывает октябрьские кампании. Исходы учтены по состоянию на 22 ноября. Идентификаторы заменены условными кодами, данные агрегированы до уровня кампании.
